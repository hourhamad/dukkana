# دكّانة | Dukkana

مساعد ذكي يمكّن صاحبات المشاريع المنزلية والأسر المنتجة رقمياً وتمويلياً.

## المشكلة
كثير من صاحبات المشاريع المنزلية يعتمدن على البيع عبر الواتساب والمعارف فقط،
دون هوية رقمية أو سجل مبيعات موثّق، مما يحدّ من وصولهن للأسواق وللتمويل الميسّر.

## الحل
1. **الهوية الرقمية:** توليد أوصاف منتجات ومحتوى تسويقي وصفحة متجر من صور المنتجات.
2. **سجل المبيعات:** تسجيل تلقائي لكل طلب يمر عبر المساعد.
3. **مؤشر الجاهزية التمويلية:** درجة من 100 مبنية على انتظام المبيعات ونموها،
   تُقدَّم لجهات التمويل الميسّر.

## التقنيات المخطط لها
- واجهة محادثة (ويب / واتساب)
- نموذج لغوي لتوليد المحتوى
- قاعدة بيانات للطلبات ولوحة مؤشرات

## الحالة
🚧 قيد التطوير — مشارك في هاكاثون روّاد (برمجان)، مسار تمكين المرأة وريادة المستقبل.
